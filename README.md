# Vencord-Supportka v1.2.6

Плагин Supportka для Vencord: кнопки Мальчик, Девочка и Не-допуск, мьют и отключение от войса в профиле пользователя.

## Что делает

- **Мальчик**: отправляет ID пользователя в настроенный канал.
- **Девочка**: отправляет ID в канал Девочка, затем в канал Мальчик.
- **Не-допуск**: открывает окно с быстрыми причинами и отправляет ID и причину в канал Не-допуск.
- **Замутить/Размутить**: мьютит или размьючивает участника, если он в войсе.
- **Отключить**: отключает участника от голосового канала.
- Сообщения отправляются только в заданные каналы. Плагин не создает каналы и не использует запасные.

## Обновления

- Плагин проверяет новые релизы при запуске и каждые 4 часа.
- Кнопка Проверить и установить в настройках скачивает ZIP с GitHub, проверяет SHA-256, заменяет файлы и предлагает перезапустить Discord.
- Перед заменой создается резервная копия. При ошибке файлы восстанавливаются.
- Если автоустановка недоступна, ZIP можно скачать и установить вручную.

## Установка

1. Скачай [supportka-v1.2.6.zip](https://github.com/Akimuska/Vencord-Supportka/releases/download/v1.2.6/supportka-v1.2.6.zip).
2. Полностью закрой Discord, включая значок в системном трее.
3. Распакуй папку supportka-v1.2.6 из архива.
4. Запусти drop-in.bat.
5. Запусти Discord.
6. Плагин включится автоматически. Версия отображается в настройках.

Установщик отключает автообновление Vencord, чтобы оно не заменило сборку Supportka. Если обновляешь Vencord вручную, снова запусти drop-in.bat.

## Настройки

- Каналы для Мальчик, Девочка и Не-допуск.
- Пресеты причин для Не-допуск, через точку с запятой.
- Автопроверка обновлений.
- Кнопка Проверить и установить.
