# Vencord-Supportka

Плагин supportka для Vencord — кнопки Мальчик/Девочка/Отказ и мьют прямо из профиля пользователя.

## Что делает

- **Мальчик** — отправляет ID пользователя в настроенный канал
- **Девочка** — отправляет ID в канал «девочка», затем в «мальчик»
- **Отказ** — открывает модалку с пресетами причин отказа, отправляет `ID причина` в канал отказа
- **Замутить/Размутить** — мьют пользователя на сервере (работает только если он в войсе)

## Установка

1. Скачай `supportka-v1.2.zip` из [последнего релиза](https://github.com/kimvk4023-lgtm/Vencord-Supportka/releases)
2. Полностью закрой Discord, включая значок в системном трее
3. Распакуй папку `supportka-v1.2` из архива
4. Запусти `drop-in.bat`
5. Запусти Discord
6. Плагин автоматически включится

## Настройки

- **Пресеты причин отказа** — быстрые причины через точку с запятой (например: `Молчит в войсе, в лс отписано;АртёмВавилов;12 лет, ;Оскорбляет`)
