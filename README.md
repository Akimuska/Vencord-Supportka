# Vencord-Supportka

**Плагин supportka для Vencord** — упрощённая версия без памятки и оверлея, только кнопки Мальчик/Девочка/Отказ и мьют прямо из профиля пользователя.

## Что делает

- **Мальчик** — отправляет ID пользователя в настроенный канал
- **Девочка** — отправляет ID в канал «девочка», затем в «мальчик»
- **Отказ** — открывает модалку с пресетами причин отказа, отправляет `ID причина` в канал отказа
- **Замутить/Размутить** — мьют пользователя на сервере (работает только если он в войсе)

## Установка

1. Скачай [последний релиз](https://github.com/kimvk4023-lgtm/Vencord-Supportka/releases) (файл `supportka-vX.X.X.zip`)
2. Распакуй архив на рабочий стол
3. Запусти `drop-in.bat`
4. Перезапусти Discord/Vesktop
5. Включи плагин в настройках Vencord: **Settings > Vencord > Plugins > supportka**

## Настройки

- **Пресеты причин отказа** — быстрые причины через точку с запятой (например: `Молчит в войсе, в лс отписано;АртёмВавилов;12 лет, ;Оскорбляет`)
